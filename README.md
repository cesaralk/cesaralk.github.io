## Publish as your main GitHub Pages portfolio

For the clean URL `https://cesaralk.github.io/`:

1. Create a **public** GitHub repository named exactly `cesaralk.github.io`.
2. Put every file from this folder in the repository root.
3. Commit and push to `main`.
4. In GitHub open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/(root)`, then save.

The site has no build step and will publish directly.
